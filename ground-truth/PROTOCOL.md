# Протокол независимой разметки датасета (Ground-Truth Protocol)

## 1. Назначение протокола
Данный протокол определяет строгие, объективные правила разметки ончейн-адресов Solana для оценки качества детекции внешними аудиторами.
Разметка производится строго независимо от кодовой базы, внутренних правил, порогов и вердиктов Wallet Radar.

---

## 2. Определения классов

Класс кошелька определяется исключительно фактическим **ОНЧЕЙН-ИСХОДОМ** (`outcome`), наступившим после даты отсечения (`cutoff_date`), а не внешним видом, историей или эвристиками:

### 2.1. DANGEROUS (Опасный)
* **Определение:** Последующие операции или смарт-контракты кошелька привели к подтверждённой потере средств пользователей/контрагентов из-за токсичной механики:
  - невозможность продажи токена (honeypot, вредоносный запрет трансфера);
  - несанкционированный вывод ликвидности создателем (rugpull / liquidity drain);
  - эксплойт смарт-контракта, манипуляция оракулом или кража приватных ключей (wallet drainer).
* **Жёсткое правило:** Запрещено использовать наличие `freezeAuthority` как единственное доказательство класса `DANGEROUS` (у легитимных стейблкоинов USDC и USDT он активен). Для `DANGEROUS` обязателен зафиксированный факт токсичного исхода, подтверждённый внешним независимым источником.
* **Временное ограничение:** Дата исхода (`event_date`) должна быть строго позже даты отсечения (`cutoff_date`), то есть `event_date > cutoff_date`.

### 2.2. SAFE (Безопасный)
* **Определение:** Наличие явного положительного независимого свидетельства:
  - публичный проверенный лейбл протокола, биржи или инфраструктурного сервиса;
  - подтверждённая валидаторская учетная запись в реестре консенсуса Solana (`getVoteAccounts`);
  - задокументированная институциональная кастодиальная деятельность без инцидентов безопасности.
* **Жёсткое правило:** Отсутствие красных флагов свидетельством безопасности НЕ считается. Обычный кошелёк без положительного внешнего свидетельства не может быть отнесён к `SAFE`.
* **Жёсткие негативы (Hard Negatives):** В класс `SAFE` обязательно включаются кошельки, активно взаимодействующие с токенами, имеющими `freezeAuthority` (USDC, USDT), для проверки системы на устойчивость к ложным срабатываниям.

### 2.3. UNCERTAIN (Под сомнением / Неопределённый)
* **Определение:** Свидетельств для однозначного отнесения к `SAFE` или `DANGEROUS` недостаточно либо они противоречат друг другу:
  - арбитражные и MEV-боты (сэндвич-боты): приносят slippage-убытки розничным трейдерам, но действуют строго в рамках правил смарт-контрактов без взлома ключей;
  - счета с противоречивыми юридическими или техническими оценками (например, инциденты, оспоренные в судебном порядке как «protocol as designed»);
  - кошельки с единичными транзакциями без дальнейшей истории, где невозможно доказать ни безопасность, ни злонамеренность.

## 3. Запрещённые практики
1. **Запрет смешивания с Wallet Radar:** Запрещено использовать вердикты (`VERIFIED_SAFE`, `LOW_TRUST_WARMING`, `BLOCKED`), термины правил (`TOXIC_MINT`, `DORMANT_ACTIVE`, `ACTIVITY_BURST` и др.) или субъективные предположения в качестве источника меток.
2. **Запрет заглядывания в будущее (Zero Lookahead Bias):** Все признаки, доступные системе на момент принятия решения, должны быть строго ограничены датой `cutoff_date`. Факт исхода `event_date` находится в будущем относительно `cutoff_date`.
3. **Запрет записей без подтверждения:** Запись без `source_url`, `event_date` или `checked_at` признаётся юридически и технически недействительной.

## 4. Каталог проверенных источников данных

Для каждого источника проверена доступность прямым запросом:

### Источник 1: Solana RPC (Helius Mainnet Node)
* **Тип:** `onchain_fact`
* **Назначение:** Получение ончейн-аккаунтов, истории подписей (`getSignaturesForAddress`), парсинг транзакций (`getTransaction`).
* **Статус проверки:** 🟢 **ДОСТУПЕН** (HTTP 200, slot 451575686).

### Источник 2: Solana Foundation Public RPC (`https://api.mainnet-beta.solana.com`)
* **Тип:** `onchain_fact`
* **Назначение:** Независимая ончейн-валидация слотов и балансов.
* **Статус проверки:** 🟢 **ДОСТУПЕН** (HTTP 200, slot 451575685).

### Источник 3: Реестр валидаторов Solana (`getVoteAccounts`)
* **Тип:** `onchain_fact` / `public_label`
* **Назначение:** Идентификация активных валидаторов консенсуса Solana, голосующих аккаунтов и их стейка.
* **Статус проверки:** 🟢 **ДОСТУПЕН** (HTTP 200, 675 текущих валидаторов).

### Источник 4: DeFiLlama Hacks Database (`https://api.llama.fi/hacks`)
* **Тип:** `third_party_database`
* **Назначение:** Верификация дат инцидентов, названий взломанных протоколов и техник эксплойтов.
* **Статус проверки:** 🟢 **ДОСТУПЕН** (HTTP 200, 1289 инцидентов, 54 инцидента в экосистеме Solana).

### Источник 5: Публичные отчёты аудиторов и регуляторов (CertiK, Solana Foundation, US DOJ, OtterSec)
* **Тип:** `public_incident_report`
* **Назначение:** Документированные пост-мортемы и судебные материалы с подтверждёнными адресами злоумышленников.
* **Статус проверки:** 🟢 **ДОСТУПЕН** (публичные веб-отчёты доступны для чтения и перекрёстной верификации).

### Источник 6: Solscan API (`https://api.solscan.io`)
* **Статус проверки:** 🔴 **НЕ ПРОВЕРЕНО / НЕДОСТУПЕН** (Cloudflare / WAF блокирует прямые API-запросы без корпоративной авторизации). Для разметки прямой API Solscan **НЕ ИСПОЛЬЗУЕТСЯ**; используется публичный веб-интерфейс `solscan.io/account/...` исключительно как ссылка на эксплорер.

### Источник 7: Jupiter Token List API (`https://tokens.jup.ag/tokens`)
* **Статус проверки:** 🔴 **НЕ ПРОВЕРЕНО / НЕДОСТУПЕН** (сбой разрешения DNS / сетевой таймаут). В разметке **НЕ ИСПОЛЬЗУЕТСЯ**.
