Wallet Radar answers "what changed, and does it matter?" — for a watchlist of wallets, continuously. A collector builds a per-wallet baseline; a deterministic analyzer fires anomaly rules with structured evidence (tx signatures, numbers); an optional one-call LLM digest turns it into a sentence; alerts go to Telegram. Any agent can call it as an MCP tool before it acts.
DORMANT_ACTIVEreactivated after N days of silence
ACTIVITY_BURSTK+ tx in a short window vs. normal rate
NEW_VENUEfirst swap on an unseen DEX / protocol
LARGE_SWAPswap > N× the wallet's own USD median
CONCENTRATIONrepeated swaps into the same token
NEW_PROTOCOLfirst interaction with an unseen program
